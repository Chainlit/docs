<Warning>
The Chainlit repository is archived. We no longer provide active maintenance, bug fixes, security updates, or support.
</Warning>

We built Chainlit in the early days of conversational AI to help developers turn language models into useful applications. Thank you for the enthusiasm, contributions, and care you brought to the community.

As AI tools and the way we build software have evolved, we have been reconsidering Chainlit’s future. We explored ways to sustain its maintenance, but could not establish a durable path, and we no longer have the capacity to maintain it.

## What this means for users

The source code remains available under its existing [Apache 2.0 license](https://github.com/Chainlit/chainlit/blob/main/LICENSE). This documentation is available as a reference for existing applications; it does not imply that the project is maintained or that its examples remain compatible with current services and dependencies.

We know some of you still rely on Chainlit. Continued use requires your own arrangements for maintenance and security, including assessing vulnerabilities and updating dependencies. Archiving the project does not resolve security issues in existing deployments.

Before starting a new project or deploying an existing application, consider whether you can maintain it or move to an actively maintained alternative.

Thank you for everything you built and shared.
